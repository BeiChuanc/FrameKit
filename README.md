# 帧工坊 FrameKit V1.0.5

**柠檬奶昔** · 视频序列帧与图像处理工具。支持视频裁剪、按时间段抽帧、色键抠像、动画预览和资源导出，也可单独处理本地图片。两端内置青柠和琥珀主题，素材在本机处理。

## 打开工具

| 版本 | 入口 | 使用条件 |
|---|---|---|
| Web | [GitHub Pages 入口](https://beichuanc.github.io/FrameKit/) | 使用支持所选视频编码的浏览器 |
| Windows 桌面端 | [打开 FrameKit.exe](./Desktop/FrameKit.exe) | 64 位 Windows 和 Microsoft Edge WebView2 Runtime |

桌面端下载后双击运行。浏览器或桌面程序无法解码视频时，可以改用 H.264 编码的 MP4 或 WebM。

## 视频转序列帧

1. 在「序列帧」中拖入视频，或点击「选择本地视频」。
2. 在参考画面上框选保留区域，或用百分比微调裁剪位置和尺寸。设置片段起止时间和每秒提取帧数，然后点击「提取帧」。
3. 如需透明背景，在参考帧上点击背景色，按预览调整容差、软边和去溢色等参数。需要保留背景时可以跳过取色。
4. 点击「生成序列图」。在预览区切换拼图和动画，在导出区设置列数、间距及单帧尺寸。用于游戏精灵图时可将间距设为 `0`。
5. 选择导出格式。

| 格式 | 输出内容 |
|---|---|
| 序列图 PNG | 将普通或透明序列帧拼到一张图中 |
| 动画 GIF | 将序列帧导出为可播放动画 |
| 透明单帧 ZIP | 抠像完成后将每一帧存成独立的透明 PNG |
| Spine ZIP | 点击「进入 Spine 动画」后设置动画名、导出帧率等参数，导出骨骼 JSON、逐帧 PNG 和导入说明 |

抽帧会占用内存。处理较长或高分辨率视频时，可以先缩短片段、缩小裁剪范围或降低抽帧帧率。

## 图片工具

- **背景抠图**。导入图片，点选背景色并微调边缘，生成并下载透明 PNG。
- **图片尺寸**。多选 JPG、PNG 或 WebP，设置目标尺寸与输出格式，生成后可单张下载或打包 ZIP。
- **图片压缩**。多选图片，设置压缩质量和输出格式。通过对比滑块检查画质后，可单张下载或打包 ZIP。

## 文件位置

- `Desktop/` 保存 Windows 桌面版。
- `docs/` 保存 Web 站点文件。GitHub Pages 的发布源为 `main` 分支的 `/docs`。已安装 Python 时，在此目录运行 `python -m http.server 8080 --bind 127.0.0.1`，然后打开 [本地预览](http://127.0.0.1:8080/)。
- `Source/` 提供对应版本的源代码和构建说明。
